## Internal

I built Webskiff, an experimental keyboard-first Chromium browser that runs
inside a terminal. The preview includes Vim navigation, live page search,
configurable shortcuts, and keyboard help.

The initial locally tested platform is macOS Apple Silicon. Linux is experimental.
The release page lists tested terminal combinations and current limits.

This is a personal prototype, not a company-endorsed or approved browser.
Please use public/local pages only. Company accounts, sensitive data, corporate
SSO/MFA, proxies/certificates, accessibility, and device-policy compatibility
require separate approval and validation.
